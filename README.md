# Allston Son Dakika

Allston Son Dakika is an independent satirical news publication from Allston, Massachusetts. It started as an Instagram account sharing stories and inside jokes among friends, and grew into a website where those stories have a home.

The site presents its articles in a newspaper-inspired layout, with Turkish and English editions.

**Visit:** [allstonsondakika.com](https://allstonsondakika.com) · [Türkçe](https://allstonsondakika.com/tr/) · [English](https://allstonsondakika.com/en/)

Originally hosted on GitHub Pages, the website now runs on Railway under its own domain. This repository contains its source code.
